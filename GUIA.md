# Guía de inicio

1. Compila con `zsh build.sh` y descomprime el ZIP creado en `dist/`.
2. Abre PDF417 Creator y selecciona un formato con generador disponible.
3. Introduce un texto de prueba, por ejemplo `DEMO-001`; ajusta escala, margen y colores manteniendo buen contraste.
4. Genera el código y utiliza la verificación disponible. Comprueba también la lectura con el equipo de destino.
5. Exporta una copia en el formato que necesites. El SVG contiene PNG incrustado.
6. Guarda el proyecto `.codestudio` si quieres continuar editándolo después.
7. Para lectura, abre una imagen de prueba compatible. Para series o CSV, utiliza nombres y datos sintéticos al conocer la herramienta.
8. La transferencia al teléfono requiere la misma red local. Cancela el servidor temporal al terminar; el enlace no sustituye una conexión cifrada.

La app contiene opciones de inventario y un catálogo de formatos. Algunos formatos son referencias y no admiten generación. Los datos del inventario, historial y borradores pertenecen a tu Mac y no se publican en el repositorio.
